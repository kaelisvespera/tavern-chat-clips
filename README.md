# 聊天摘录

适配 TauriTavern 2.4.0 的前端扩展。同一楼可以反复收藏，每点一次就保存一份独立快照。第 20 楼先生成一个番外，收藏后在原楼生成另一个，两份内容都能留在收藏夹里。

## 安装

在 TT 打开「扩展 → 安装扩展」，粘贴仓库地址 `https://github.com/kaelisvespera/tavern-chat-clips`。TT 的 Git 安装器需要能匿名访问仓库。手动安装时，把含 `manifest.json` 的 `tavern-chat-clips` 文件夹放进 TT 数据目录的 `default-user/extensions/`，再重新打开 TT。扩展可独立运行。[TT 2.4.0 扩展文档](https://github.com/Darkatse/TauriTavern/blob/v2.4.0/default/skills/tt-extensions/SKILL.md)

## 用法

- **反复收藏同一楼**。展开消息操作，点书签图标「收藏整楼」。同一个图标可以反复点击，正文相同也可以另存。每份快照都可以单独加标题、笔记或移除。
- **收藏一段话**。在消息正文选中文字，点「收藏选中文字」。可以继续选同楼的另一段再保存。
- **打开收藏夹**。在输入框旁的魔法棒菜单选「聊天摘录」。在收藏夹按当前聊天或全部聊天筛选，或者切到「聊天搜索」查找当前聊天。桌面端也可用 `Ctrl/⌘ + Shift + F` 打开搜索。
- **回到原文**。「回到原文」定位来源楼层。若来源内容已被删除或替换，收藏夹仍可阅读当时的快照。定位会沿用聊天当前展示的回复版本。

整楼快照保存当时显示的正文和能读取的已加载图片。可读的内嵌页面也会保存文字。搜索基于当前聊天保存的消息正文，旧收藏中携带的 HTML 会按纯文本导入。

## 迁移和备份

在原来使用脚本的同一个 TT 环境打开「聊天摘录」，点「迁移旧收藏」。也可在旧脚本中导出收藏，再点新插件的「导入备份」并选择旧 JSON。若两个入口同时显示，可停用旧脚本。

收藏储存在当前酒馆环境的 IndexedDB，可以用「导出备份」迁移到另一台设备。重复导入同一份备份时，已经有相同收藏编号的记录会跳过。

旧版聊天记录管理脚本由千秋梦编写。插件采用独立实现，兼容旧收藏数据。
