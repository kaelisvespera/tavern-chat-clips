# 聊天记录管理

千秋梦的酒馆助手脚本「聊天记录管理」经授权移植为 TauriTavern 2.4.0 扩展。搜索面板、收藏列表、角色展馆和阅读编辑窗口沿用原脚本。

同一楼的爱心可以反复点。每次确认收藏都新增一份独立快照，正文相同也可以另存。例如第 20 楼先收藏第一个番外，后来在这楼跑出第二个番外，再点爱心，两份都能保留。

## 安装和升级

在 TT 打开「扩展 → 安装扩展」，使用 [kaelisvespera/tavern-chat-clips](https://github.com/kaelisvespera/tavern-chat-clips)。已经安装的用户可在「管理扩展」中更新并重新打开 TT。也可把含 `manifest.json` 的 `tavern-chat-clips` 文件夹放进 TT 数据目录的 `default-user/extensions/`。[TT 2.4.0 扩展文档](https://github.com/Darkatse/TauriTavern/blob/v2.4.0/default/skills/tt-extensions/SKILL.md)

插件可独立运行。如果旧的酒馆助手脚本仍在运行，升级后停用旧脚本即可只保留一个入口。

## 使用

- **搜索收藏**。从所有聊天的收藏标题和金句查找，结果按角色分组。输入区、扩展菜单和桌面快捷键 `Ctrl/⌘ + Shift + F` 均可打开面板。启用 QR助手后，也可从小火箭的「聊天记录管理 → 聊天搜索」进入。[QR助手](https://github.com/uhhhh15/QR)
- **收藏和展馆**。点消息操作中的爱心，填写可选标题和金句。「收藏」显示当前聊天，「展馆」按角色名合并各聊天的收藏。同名角色的每份快照仍可独立阅读、编辑、定位和删除。
- **阅读和截图**。阅读窗支持上一条、下一条、长图 PNG 导出和截图用户名替换。点爱心时保存正文当时可读取的渲染结果，包括来自聊天页的样式、伪元素，以及 TT、酒馆助手和小白 X 的前端预览。旧收藏中仍有样式或内嵌源码的，可直接用于阅读和截图。截图使用随插件附带的 `modern-screenshot` 4.7.0。[上游许可证](vendor/modern-screenshot-LICENSE.txt)

阅读窗顶部可把正文和金句调为 80%–160%。点中间百分比恢复 100%，设置会记在当前设备上。截图沿用当前字号及内嵌页面原来的版式。长文以每张最高 4096 像素分段渲染，按编号逐张保存 PNG。
- **面板高度**。在「更多 → 面板高度」调整上限，设置会记在当前设备上。主面板和阅读窗共用高度设置及顶部位置。点面板外会返回上一级，在主面板首页点外侧会直接关闭。
- **收藏备份**。在「更多」中导出完整或精简收藏 JSON，也可以导入备份。精简收藏可用「定位」补载正文。

## 旧收藏

同一个酒馆环境中的原脚本收藏直接读取原有数据库。上一版扩展 `1.0.0` 的收藏会自动合并，原库保留，重复升级时按收藏编号识别已有条目。换设备时可以用「更多 → 导出」和「导入」迁移，支持原脚本及 `1.0.0` 的收藏备份。

收藏保存当前消息正文、可读取的渲染内容和图片。隔离的内嵌页面使用模板中的静态样式和内容，脚本控制的选中状态、主题切换等效果取决于收藏时可读取的渲染结果。
